# Классификация описаний уязвимостей

Модель на RuBERT, которая по тексту определяет, описана ли в нем уязвимость, и если да — какого
она типа: уязвимость кода, архитектуры или многофакторная.

Просьба обратить внимание: модель работает с текстами описаний, а не с программами. Искать уязвимости в коде она не умеет.

## Содержимое

- `main.py` — модель, обучение и предсказание
- `data_utils.py` — загрузка и очистка данных, разбиение на выборки, метрики
- `demo-data/` — 20 демонстрационных примеров (10 уязвимостей и 10 обычных технических текстов)
- `requirements.txt` — зависимости
- `rubert_metrics.json` — результаты одного из ранних запусков (подробнее ниже)

Модель — `DeepPavlov/rubert-base-cased` и две небольшие «головы» поверх нее: одна решает,
уязвимость это или нет, вторая определяет тип.

## Установка

Нужен Python 3.12+. Для обучения — видеокарта (я обучал в корпоративном контуре) и доступ к huggingface.co.

```
pip install -r requirements.txt
```

## Данные

Обучающих данных в репозитории нет — это корпоративная информация. Чтобы обучить модель, положите
в папку `data/` два файла:

- `vul-desc-class.csv` — описания уязвимостей, разделитель `;`, первая строка — заголовок,
  в первом столбце текст, во втором класс («Уязвимость кода», «Уязвимость архитектуры»
  или «Уязвимость многофакторная»);
- `non-vul-desc.txt` — тексты без уязвимостей, по одному в строке.

Как это выглядит, можно посмотреть в `demo-data/`. Примеры там придуманы специально для
демонстрации, реальных продуктов в них нет.

## Обучение

```
python main.py train
```

По умолчанию: 10 эпох, батч 16, lr 2e-5, ранняя остановка, если качество на валидации не растет
3 эпохи подряд. Данные делятся 70/10/20, похожие тексты всегда попадают в одну выборку.

После обучения появятся:

- `results/rubert_metrics.json` — метрики на тесте и история обучения;
- `results/quarantine.csv` — записи, которые не пошли в обучение (пустые, без метки, с конфликтующими метками);
- `vulnerability_classifier_model/` — сама модель.

Чтобы просто проверить, что всё запускается, можно прогнать одну эпоху на демо-данных:

```
python main.py train --data-dir demo-data --results-dir demo_results --model-dir demo_model --epochs 1
```

На 20 примерах модель, конечно, ничему не научится — это только проверка, что код работает.
